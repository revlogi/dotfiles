# 极小多项式

> [!abstract] Core Idea
> 零化 $A$ 的多项式都是极小多项式 $m_A$ 的倍数，而 $m_A$ 中 $(x-\lambda)$ 的幂次恰好是 $\lambda$ 的**最大 Jordan 块阶数**：特征多项式记录每个特征值“有多少”，极小多项式记录“最长的链有多长”，因此 $A$ 可对角化当且仅当 $m_A$ 没有重根。

## 定义与关键性质

- **定义**：$m_A$ 是满足 $m_A(A) = 0$ 的、次数最低的首一多项式。
- **整除性**：如果 $p(A) = 0$，做带余除法 $p = q \cdot m_A + r$，则 $r(A) = 0$，而 $\deg r < \deg m_A$，所以 $r = 0$。因此 $m_A \mid p$。
- **Cayley–Hamilton**：特征多项式满足 $\chi_A(A) = 0$，所以 $m_A \mid \chi_A$；两者的根相同（都是 $A$ 的全部特征值），只是重数可以不同。
- **Jordan 刻画**：
  $$m_A(x) = \prod_{\lambda} (x - \lambda)^{s_\lambda}, \quad s_\lambda = \lambda\text{ 的最大 Jordan 块阶数}$$
  原因：$k$ 阶 Jordan 块 $J$ 满足 $N = J - \lambda I$ 幂零，且 $N^{k-1} \neq 0$、$N^k = 0$；分块对角矩阵被 $p$ 零化，当且仅当每一块都被零化。
- **相似不变**：$p(P^{-1}AP) = P^{-1}p(A)P$，所以相似矩阵的极小多项式相同。**反过来不成立**（见反例）。

## 怎样求 / 验证

候选首一多项式 $p$ 是 $m_A$，当且仅当：

1. $p(A) = 0$；并且
2. 对 $p$ 的每个不可约因子 $f$，$(p/f)(A) \neq 0$（不能再去掉任何一个因子）。

实际做法：从 $\chi_A$ 的因式分解出发，对每个特征值降低幂次试代入，或者直接读出 Jordan 标准形。

## 例子与反例

| 矩阵 | 极小多项式 | 说明 |
|---|---|---|
| 纯量阵 $cI$ | $x - c$ | 次数为 $1$；反之，$m_A$ 为一次时 $A$ 必为纯量阵 |
| 秩 $1$ 矩阵 $A = uv^\top$（$n \ge 2$） | $\operatorname{tr} A \neq 0$ 时为 $x(x - \operatorname{tr} A)$；$\operatorname{tr} A = 0$ 时为 $x^2$ | 由 $A^2 = u(v^\top u)v^\top = (\operatorname{tr} A)A$ 得到；故秩 $1$ 矩阵可对角化 $\iff \operatorname{tr} A \neq 0$ |
| $\operatorname{diag}(J_2(0), J_2(0))$ vs $\operatorname{diag}(J_2(0), J_1(0), J_1(0))$ | 都是 $x^2$，特征多项式都是 $x^4$ | Jordan 形不同，因此**不相似**：相同的极小多项式推不出相似 |

## 陷阱

- 只验证 $p(A) = 0$，只能说明 $m_A \mid p$，不能说明 $p$ 就是极小多项式。
- 极小多项式相同、特征多项式也相同，仍然可能不相似（上面的反例）；Jordan 形才是完全不变量。
- “最大 Jordan 块的阶数”针对的是每个特征值 $\lambda$，而不是整个矩阵。

# 极小多项式

> [!abstract] Core Idea
> 零化 A 的多项式都是极小多项式 m_A 的倍数，而 m_A 中 (x−λ) 的幂次恰好是 λ 的**最大 Jordan 块阶数**：特征多项式记录每个特征值“有多少”，极小多项式记录“最长的链有多长”，因此 A 可对角化当且仅当 m_A 没有重根。

## 定义与关键性质

- **定义**：m_A 是满足 m_A(A) = 0 的、次数最低的首一多项式。
- **整除性**：如果 p(A) = 0，做带余除法 p = q·m_A + r，则 r(A) = 0，而 deg r < deg m_A，所以 r = 0。因此 m_A | p。
- **Cayley–Hamilton**：特征多项式满足 χ_A(A) = 0，所以 m_A | χ_A；两者的根相同（都是 A 的全部特征值），只是重数可以不同。
- **Jordan 刻画**：m_A = ∏ (x − λ)^{s_λ}，s_λ = λ 的最大 Jordan 块阶数。
  原因：k 阶 Jordan 块 J 满足 J − λI = N 幂零，且 N^{k−1} ≠ 0、N^k = 0；分块对角矩阵被 p 零化，当且仅当每一块都被零化。
- **相似不变**：p(P⁻¹AP) = P⁻¹p(A)P，所以相似矩阵的极小多项式相同。**反过来不成立**（见反例）。

## 怎样求 / 验证

候选多项式 p（首一）是 m_A，当且仅当：

1. p(A) = 0；并且
2. 对 p 的每个不可约因子 f，(p/f)(A) ≠ 0（不能再去掉任何一个因子）。

实际做法：从 χ_A 的因式分解出发，对每个特征值，降低它的幂次试代入，或者直接读出 Jordan 标准形。

## 例子与反例

| 矩阵 | 极小多项式 | 说明 |
|---|---|---|
| 纯量阵 cI | x − c | 次数为 1；反之，m_A 为一次时 A 必为纯量阵 |
| 秩 1 矩阵 A = uvᵀ（n ≥ 2） | tr A ≠ 0 时为 x(x − tr A)；tr A = 0 时为 x² | 由 A² = u(vᵀu)vᵀ = (tr A)·A 得到；所以秩 1 矩阵可对角化，当且仅当 tr A ≠ 0 |
| diag(J₂(0), J₂(0)) vs diag(J₂(0), J₁(0), J₁(0)) | 都是 x²，特征多项式都是 x⁴ | Jordan 形不同，因此**不相似**：相同的极小多项式推不出相似 |

## 陷阱

- 只验证 p(A) = 0，只能说明 m_A | p，不能说明 p 就是极小多项式。
- 极小多项式相同、特征多项式也相同，仍然可能不相似（上面的反例）；Jordan 形才是完全不变量。
- “最大 Jordan 块的阶数”针对的是每个特征值，而不是整个矩阵。

# 概念名称

## Core Idea
用 1–2 句直接说明知识的核心关系；可用一个稳定 Claim ID [C1]。不写用户学到了什么。

## Mechanism
解释 Core Idea 的关键关系，保留必要定义、公式或类型 [C2]。

## Recall
1–3 个重建机制或判断适用条件的问题。

## Learning State
